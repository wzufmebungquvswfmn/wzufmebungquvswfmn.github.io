# 集合数据结构

Python 内置了几种常用的容器类型，再加上 `collections`、`heapq`、`bisect` 这几个标准库模块，日常和刷题遇到的绝大多数场景就够用了。

## 基础容器

- [list](集合数据结构/list.md)：有序、可变、允许重复元素
- [tuple](集合数据结构/tuple.md)：有序、不可变
- [dict](集合数据结构/dict.md)：键值映射，键唯一且可哈希
- [set](集合数据结构/set.md)：元素唯一且可哈希

## 常用标准库

- [collections 模块](集合数据结构/collections.md)：`deque`、`Counter`、`defaultdict`、`OrderedDict` 等
- [heapq](集合数据结构/heapq.md)：堆 / 优先队列
- [bisect](集合数据结构/bisect.md)：有序列表的二分查找

## 如何选择

| 需求 | 选择 |
| --- | --- |
| 需要顺序、频繁按下标增删改 | `list` |
| 需要不可变，或作为 `dict` 的键 / `set` 的元素 | `tuple` |
| 通过键快速查找、计数、分组 | `dict` |
| 去重、判重、集合运算 | `set` |
| 需要有序的键值结构 | `dict`（Python 3.7 起保持插入顺序） |
| 频繁在两端增删、BFS、滑动窗口 | `collections.deque` |
| 计数 | `collections.Counter` |
| 分组、建图、带默认值的 dict | `collections.defaultdict` |
| 频繁取最小 / 最大元素 | `heapq` |
| 有序列表上二分查找 | `bisect` |
| 强制有序且支持范围查询 | 第三方库 `sortedcontainers` |

最常用的还是 `list` 和 `dict`，刷题时再加上 `collections`、`heapq`、`bisect`。

## 复杂度速查

设 `n` 为元素个数。

| 操作 | list | dict | set |
| --- | --- | --- | --- |
| 按下标 / 键访问 | O(1) | O(1) | — |
| 查找某个值是否存在 | O(n) | O(1) | O(1) |
| 尾部插入 | O(1) 均摊 | O(1) 均摊 | O(1) 均摊 |
| 头部插入 | O(n) | — | — |
| 按下标 / 键删除 | O(n) | O(1) | O(1) |

需要注意，`dict` 和 `set` 的 `O(1)` 指的是平均复杂度，最坏情况下会退化为 `O(n)`。
